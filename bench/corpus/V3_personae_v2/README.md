# Synthetic persona corpus (V3, n=50)

`personae_extra.json` — the canonical 50-persona synthetic corpus used in the paper.

Each persona contains:

- `backstory`: a ~500-word first-person backstory generated by Claude Sonnet 4.6 with controlled diversity (occupation, geography, hobbies, health conditions). Used as the "history" both substrates write into.
- `main_qa`: per-persona main-axis QA pairs used for §4.1 behavioral evaluation.
- presence/absence probes: used for §4.2 calibration evaluation. Presence probes ask facts that ARE in the backstory; absence probes ask facts that ARE NOT (and the correct response is to abstain).

`gen.log` is the generation log from `experiments/V3a_personae_gen.py`, kept for reproducibility audit.

## Regenerating from scratch

```bash
export AWS_PROFILE=<your-bedrock-profile>
python bench/experiments/V3a_personae_gen.py --n 50 --seed 42
```

The shipped corpus uses seed 42 and the default n=50. Any variation in the upstream Bedrock model behavior over time will produce a different corpus; pin to the shipped JSON for byte-identical reproduction of the paper numbers.
